Apenas tentando recriar a aparência e funcionalidades do Windows 10 (de forma muito idêntica), que pode ser visualizado em browsers.

> [!NOTE]
> *Este projeto não tem nenhuma relação com a Microsoft, desenvolvedore do Sistema Operacional Windows. Todos os direitors estão reservados à Microsoft.*

---
## Metas
- [ ] Aparência idêntica ao Windows 10
- [ ] Tela de carregamento igual à tela de inicialização do Windows
- [ ] Nome e local de arquivos na mesma estrutura do Windows

*As metas podem ser atualizadas*

> [!IMPORTANT]
> Anteriormente, o código do backend utilizava PHP . Agora, estou atualizando o código para utilizar Node.JS.
>
> Eu tinha feito uma lógica estranha para o carregamento de "executáveis" diferentes. Os arquivos PHPs podiam carregar outros PHPs, que carregavam outros e outros... era uma bagunça
>
> Toda essa parte de carregar "executáveis" estará presente no frontend.
